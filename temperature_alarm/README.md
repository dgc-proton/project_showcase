
## Digital Design Course - Temperature Alarm

The digital design course included several projects, one of which was designing and building a PCB that was a temperature alarm with an audible and visual warning if a given temperature was exceeded, and a reset button. Mine used an ATTiny85 programmed using C and AVR header files.
